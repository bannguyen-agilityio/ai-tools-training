## Steps

1. Tests first: pro-rata table, loop detection (direct and indirect), 403 matrix, audit assertions.
2. Pure `prorata(start_date, year, entitlement)`: months remaining = 12 − (start month − 1) − (1 if start day > 15 else 0); `round_half_up_to_0.5`.
3. Employee create/edit in one transaction: validate domain, loop check (recursive), write `prorata` ledger entries for Annual and Sick when start is in the current year (else normal `entitlement`), call `issue_invite`, audit.
4. Edit: manager/team/role changes audited with before/after (role change is an R30 action).
5. Teams CRUD.
6. HR Employees UI: create/edit, assign manager, team.
