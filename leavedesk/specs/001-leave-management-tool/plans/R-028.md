# Plan 21: R28 monthly export (P2, ships Mon 16 Nov 2026)

Phase P2. Depends on: 13, 08 (balances), 18 (query shapes). Blocks: none.

## Requirements and acceptance criteria

- **R28**: HR selects a month and exports Excel or CSV in under 10 minutes of effort, containing days taken per employee per type, remaining balances, and who was off and when; any cell starting with `=`, `+`, `-`, `@` or tab is prefixed so spreadsheets cannot execute it; non-HR → 403; every export audited (who, month, time); file marked confidential.

Endpoint #34 (`GET /hr/reports/monthly?month=YYYY-MM&format=xlsx|csv`), file name `leave-report-YYYY-MM.<ext>`.

## Files

Create: `app/modules/reports/{router,service,repository,schemas,dependencies}.py`; `app/modules/reports/escape.py`; `app/modules/reports/writers.py` (CSV, `openpyxl`); frontend `src/features/hr/MonthlyReport.tsx` (month picker, preview, export); `tests/reports/*`.
Modify: add `openpyxl` dependency.
Delete: none.

## Steps

1. Tests first: escaping property tests, authz, audit, content fixtures.
2. Aggregation: per employee/type days in month (from active day rows of Approved requests), remaining balances (via `compute_balance`), list of leave spans.
3. Escape function applied to every string cell; verify numbers untouched.
4. Writers for CSV and xlsx with a "CONFIDENTIAL" header/title and sheet properties.
5. Response headers (`Content-Disposition`, `Cache-Control: no-store`).
6. Audit export (actor, month, format, time).
7. UI: month picker, on-screen preview, download.

## Risks and dependencies

- A-20: column layout, whether balances are as of month end, which statuses (Approved only? Pending?) are included.
- Formula injection from employee names or notes; notes should be excluded from the file (privacy rules).
- Real Sick type appears (HR only): file must never be reachable by the deputy (R36: exports excluded).
- Large-ish workbook built in memory: fine for 250 staff.
