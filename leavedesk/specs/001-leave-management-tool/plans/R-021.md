## Requirements and acceptance criteria

- **R21**: HR cancels an Approved request with a reason → Cancelled, used days refunded, employee and manager emailed; a second cancel refunds only once.

Extends endpoint #12 with the HR branch; the "HR: All leave" cancel button arrives with plan 18's list (this plan adds it to request detail so it is deliverable alone).

## Steps

1. Tests first: authz matrix, reason required, double cancel, refund exactly once under concurrency.
2. HR branch: guarded `UPDATE … WHERE version AND status='approved'`; sets `cancelled_by`, `cancel_reason`; day rows `is_active=false` (refund by derivation, no ledger row).
3. Audit with actor only (reason by id/length, not text); notify employee and the employee's manager (no reason in the manager's copy; no Sick type).
4. UI: dialog naming the exact consequence, default focus "Keep".
